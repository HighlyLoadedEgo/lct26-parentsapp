# LCT Parents App

Мобильное приложение для родителей к детской финансовой игре. Родитель видит,
чему ребёнок научился в игре, и выдаёт задания из реальной жизни с наградами.
Приложение для Android, устанавливается через RuStore.

## Для кого это приложение

Для родителей, которые хотят понимать прогресс ребёнка в игре и подкреплять
игровые навыки реальными делами: поход в магазин, планирование выходных и т.д.
Никаких специальных знаний не нужно — всё управляется с нескольких экранов.

## Как начать пользоваться

1. **Установите приложение** из RuStore на свой телефон.
2. **Придумайте PIN-код** из 4 цифр при первом запуске. Он защищает данные
   ребёнка: приложение спрашивает PIN при каждом открытии и после сворачивания.
   Запомните код — восстановление забытого PIN в приложении не предусмотрено.
3. **Подключите ребёнка.** На главном экране «Родительский режим» нажмите
   «Сканировать QR-код» и отсканируйте QR из детского приложения на телефоне
   ребёнка. Если QR недоступен, выберите «Ввести ID вручную» и введите ID
   питомца — его можно взять у ребёнка из детского приложения.
4. **Готово.** Отчёт откроется автоматически и будет открываться сам при
   каждом входе, пока привязка не сброшена.

## Что есть на экранах

**Отчёт (главный экран).** Показывает питомца ребёнка, баланс монет
(доступно и накоплено) и список из 12 навыков с пометками: «Освоен»,
«Тренируется», «Есть трудности» или «Нет данных». Данные — по последней
синхронизации детского приложения: если ребёнок давно не заходил в игру,
данных может не быть. Кнопка «Обновить отчёт» подтягивает свежие данные.

**Навыки и материалы для разговора.** Нажмите на навык, чтобы открыть тему:
чему учится ребёнок, история для разговора, вопросы, которые можно обсудить
за ужином, и что важно родителю. Внизу — научные источники с кликабельными
ссылками.

**Квесты из реальной жизни.** Три готовых квеста: «Поход в магазин»,
«Выходной по плану» и «Вторая жизнь вещей». В каждом — 4 шага: родитель
отмечает галочки по мере выполнения задания вместе с ребёнком. За выполненный
квест выдаётся награда — аксессуар (кепка) для питомца ребёнка. Награда
попадёт в игру, когда ребёнок синхронизирует детское приложение. Выдать одну
и ту же награду дважды нельзя.

**Сменить питомца.** Кнопка на главном экране. Сбрасывает привязку к ребёнку —
пригодится, например, если нужно подключить другого ребёнка. Сам ребёнок и его
игровой прогресс при этом не страдают.

## Обновления

Приложение обновляется через RuStore. Когда выходит новая версия, приложение
предложит скачать и установить её — нужно подтвердить. Обновление никогда не
блокирует просмотр отчёта.

## Частые вопросы

- **Отчёт пустой, «Подключите питомца»** — привязка сброшена или не сделана.
  Отсканируйте QR или введите ID вручную.
- **«Сохранение игры пока недоступно»** — ребёнку нужно сначала зайти в
  детское приложение и синхронизировать игру, потом нажать «Обновить отчёт».
- **«Не удалось загрузить отчёт»** — проверьте интернет и нажмите «Повторить».
- **5 неверных попыток PIN** — приложение требует подождать 30 секунд перед
  следующей попыткой. Это защита от подбора.
- **Защищены ли данные ребёнка?** — да: запрещены скриншоты и отображение
  содержимого в списке недавних приложений, PIN хранится только в виде хеша.

## Для разработчиков

Нативное Android-приложение на Kotlin с Jetpack Compose и Material 3.

Модули: `:app` (сборка, навигация, тема), `:core:report` (общая работа
с бэкендом), `:feature:pin`, `:feature:report`, `:feature:questions`,
`:feature:quests`, `:feature:scanner`. Подробности — в
[docs/architecture.md](docs/architecture.md), соглашения по работе — в
[AGENTS.md](AGENTS.md).

Сборка:

```bash
./gradlew :app:assembleDebug
```

Проверки перед коммитом:

```bash
./gradlew :app:testDebugUnitTest :core:report:testDebugUnitTest :feature:pin:testDebugUnitTest :feature:report:testDebugUnitTest :feature:questions:testDebugUnitTest :feature:quests:testDebugUnitTest :feature:scanner:testDebugUnitTest :app:assembleDebug :app:lintDebug
```

Android SDK указывается в `local.properties` (`sdk.dir=...`), файл не
коммитится.
