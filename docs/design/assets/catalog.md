# Parent reward cap artwork

Six icons copied byte-for-byte from LCTApp main `587af69`. The upstream import was on 2026-09-29 from Figma. All six retain the full 512 × 512 canvas and original dark background. No images were regenerated, trimmed or rescaled. Original export conversion: lossless exact WebP, method 6. Runtime loads bundled images asynchronously and uses explicit carousel bounds with ContentScale.Fit.

[Manifest](manifest.json) records output/source hashes, byte sizes, source nodes and conversion. Original PNG exports remain in the main LCTApp repository under the recorded `upstream_source_path`. The companion needs only the six standalone icons, not character age/fur models.
